# e-plantShopping

## Paradise Nursery Plant Shopping Application

e-plantShopping is a React-based shopping application for indoor houseplants. The app allows users to browse different plant categories, add products to a shopping cart, manage quantities, and view total costs.

### Features

- Landing page with company information
- Background image and Get Started button
- Product listing page with plant categories
- Shopping cart with dynamic updates
- Add to Cart functionality
- Increase and decrease quantity
- Delete items from cart
- Redux Toolkit for state management
- React Router navigation
- GitHub Pages deployment

### Technologies Used

- React
- Redux Toolkit
- React Redux
- React Router
- Vite
- CSS
